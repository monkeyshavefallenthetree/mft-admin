# Legacy HTML dashboards

Reference copies of the original single-file Firebase admin UIs.

- **`admin-dashboard-firebase.html`** — large dashboard (full feature set used to port the Next app).
- **`mft-admin-smaller/`** — smaller bundle HTML files from the old nested folder.

Open any `.html` in a browser only if you configure Firebase in that file; the supported app is the Next.js parent project.
